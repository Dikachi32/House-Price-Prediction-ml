# 🏡 House Price Prediction ML

## 📌 Overview

House Price Prediction ML is an AI-powered machine learning application designed to estimate the market value of properties based on key housing features such as square footage, number of bedrooms, bathrooms, and the age of the property.

The system uses trained regression models to deliver fast and intelligent property price predictions in real time through a simple and user-friendly interface.

## 🧠 How It Works

The application allows users to input important housing features, including:

* Square feet area (total living space)
* Number of bedrooms
* Number of bathrooms
* Age of the property

These inputs are processed and passed into a trained machine learning regression model, which predicts the estimated market value of the property instantly.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Dikachi32/house-price-prediction-ml.git
```

### 2️⃣ Navigate into the Project Folder

```bash
cd house-price-prediction-ml
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
python app.py
```
