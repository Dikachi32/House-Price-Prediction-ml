# House Price Prediction ML

## 📌 Overview
This project is a machine learning application that predicts house prices based on key property features such as area, location, number of bedrooms, number of bathrooms, and the age of the house.

The goal is to provide users with a quick and reliable estimate of property prices using a trained predictive model.

## 🚀 Features
- Predicts house prices based on user input
- Uses real-world housing features
- Simple and user-friendly interface
- Fast and efficient prediction model

## 🧠 How It Works
The application takes user inputs:
- Area
- Location
- Number of bedrooms
- Number of bathrooms
- Age of the house

These inputs are processed and passed into a trained machine learning model, which returns an estimated house price.
