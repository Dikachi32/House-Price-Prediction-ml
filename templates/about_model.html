Overview

What Kind of Model Is This?

PropertyVal uses a supervised machine learning regression model — a class of algorithms that learns the relationship between a set of input features and a continuous numerical target (in this case, house price in Naira). During training, the model is shown thousands of examples of real property records paired with their known prices. It learns the mathematical patterns that link features like area, number of bedrooms, bathrooms, and age to market value.

Once trained, the model is serialised (saved) to a house_price_model.pkl file using joblib, Python's efficient binary serialisation library. When the Flask server starts up, it loads this file into memory once — so every prediction request is instant, with no re-training required.

Algorithm

The Regression Algorithm

House price prediction is a classic regression problem. The model powering PropertyVal belongs to one of these well-established families of regression algorithms — each with its own philosophy for learning from data:

Linear / Ridge Regression

The simplest regression approach. The model fits a straight-line (hyperplane in 4D) through the training data, assigning a learned weight to each feature. For example: "every additional 100 sq ft adds approximately ₦X to the price." This model is fast, fully interpretable, and works extremely well when the relationships between features and price are roughly linear. Ridge regression adds a regularisation penalty to prevent overfitting when features are correlated.

Random Forest Regressor

An ensemble method that builds hundreds of decision trees, each trained on a random subset of the data and features. Their predictions are averaged to produce a final estimate. Random Forests naturally capture non-linear relationships — for example, the price drop caused by old age may slow down after a certain point — and are robust to outliers. This is one of the most popular choices for real-estate prediction tasks due to its excellent accuracy-to-simplicity ratio.

Gradient Boosting Regressor

Another powerful ensemble method that builds trees sequentially — each new tree learns to correct the errors made by the previous ones. Implementations like XGBoost, LightGBM, or scikit-learn's GradientBoostingRegressor often achieve state-of-the-art accuracy on tabular data like property datasets. They handle complex feature interactions automatically and tend to generalise well with proper hyperparameter tuning.

Input Features

What the Model Learns From

The model uses exactly 4 numerical features — chosen because they are the most consistently available and most predictive signals for residential property valuation. Each feature contributes to the prediction in a different way.

01

Area (sq ft)

The total living area of the property. This is typically the single strongest predictor of price — larger properties command higher values in virtually every market. The model learns the price-per-square-foot relationship from the training data, which naturally varies across property sizes.

Highest Impact
02

Bedrooms

The number of bedrooms directly signals a property's capacity and intended use. More bedrooms generally mean higher prices, though the relationship is non-linear — the jump from 1 to 2 bedrooms matters more than the jump from 5 to 6. The model learns these nuances from training examples.

High Impact
03

Bathrooms

Bathroom count is a strong proxy for overall property quality and luxury tier. More bathrooms — including half-baths (0.5) — indicate a more complete and comfortable property. The model supports 0.5 increments, allowing it to distinguish between full bathrooms and powder rooms.

Medium-High Impact
04

Age of House (years)

The age of a property affects its value in complex ways. Newer properties tend to have modern finishes, better energy efficiency, and fewer maintenance needs — all of which support higher prices. However, very old properties can also command premiums if they have historical or architectural significance. The model learns this curved relationship from data.

Moderate Impact

Performance

How Accuracy Is Measured

Regression models are evaluated using standard statistical metrics computed on a held-out test set — data the model never saw during training. These metrics measure the gap between the model's predicted prices and the actual recorded prices.

R²
R-Squared Score

Measures how much of the price variance the model explains. A score of 1.0 is perfect; 0.85+ is considered strong for real-estate data.

MAE
Mean Absolute Error

The average absolute difference between predicted and actual price. Lower is better — tells you the typical prediction error in Naira.

RMSE
Root Mean Sq. Error

Like MAE but penalises large errors more heavily. Useful for detecting cases where the model occasionally makes very large mistakes.

Important Limitations to Know

  • The model only knows what it learned from its training data. Properties in locations not represented in the training set may be estimated less accurately.
  • Only 4 features are used. Real-world prices are also affected by location, neighbourhood, proximity to amenities, market timing, and renovation quality — none of which are captured here.
  • The model produces a point estimate, not a range. Treat the output as a reference figure, not a guaranteed valuation.
  • Market prices change over time. The model reflects the price patterns present in its training data and may drift from current market conditions if not periodically retrained.
  • Extreme outliers (e.g., very large estates or distressed properties) may fall outside the model's reliable prediction range.
