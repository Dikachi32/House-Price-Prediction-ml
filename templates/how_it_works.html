How It Works

PropertyVal turns four simple inputs into a data-driven house price estimate — here's the step-by-step journey from form to prediction.

Under 2 Seconds

The entire pipeline — from your click to the displayed price — completes in milliseconds.

No Data Stored

Your property details are used only for the current prediction and are never saved to any database.

ML-Powered

A trained machine learning regression model powers every estimate — not simple averages or lookup tables.

Step by Step

The Prediction Pipeline

1

You Fill in the Property Form

On the home page, you enter four key details about the property you want to value. These four values are the exact features the model was trained on, so every field matters.

Field What to Enter Unit
AreaTotal living space of the propertySquare feet
BedroomsNumber of bedroom spacesCount (integer)
BathroomsNumber of bathroom spacesCount (0.5 increments allowed)
AgeHow many years since the property was builtYears
2

Your Browser Sends the Data to the Server

When you click Predict Price, the form submits an HTTP POST request to the Flask web server running on the backend. The data travels securely as form-encoded values.

The submit button also enters a loading state, giving you instant visual feedback while the server processes your request.

HTTP POST → Flask Route "/"
3

Flask Receives and Validates the Inputs

The Flask server reads the four form values and converts them to floating-point numbers. A validation check confirms that none of the required fields are empty. If any value is missing, the user is redirected back to the form.

# Flask extracts and casts each input area = float(request.form.get("area")) bedrooms = float(request.form.get("bedrooms")) bathrooms = float(request.form.get("bathrooms")) age = float(request.form.get("age"))
4

Data is Formatted into a Feature Array

The four inputs are arranged into a 2-D NumPy array — a single-row matrix that represents one data point. This shape matches exactly what the model expects, since it was trained on rows of four features.

# Shape: [[area, bedrooms, bathrooms, age]] our_data = [[area, bedrooms, bathrooms, age]] # e.g. [[1800.0, 3.0, 2.0, 12.0]]
Feature vector shape: (1, 4)
5

The Machine Learning Model Makes Its Prediction

The pre-trained model (loaded from house_price_model.pkl via joblib at server startup) receives the feature array and applies everything it learned during training — feature weights, decision rules, or ensemble logic — to produce a single continuous value: the estimated property price in Naira.

prediction = model.predict(our_data)[0] prediction = round(prediction, 2) # → e.g. 24500000.00
Scikit-learn Regressor → Single float output
6

The Result is Rendered Back to You

Flask passes the prediction value to the Jinja2 HTML template, which formats it with the Naira symbol (₦) and comma separators for easy reading. The result appears below the form with a smooth slide-up animation — your estimated market value, delivered in seconds.

Jinja2 template renders → ₦24,500,000.00
